# AI Vacation Planner - Backend API

## Overview

Backend API for an intelligent vacation planning assistant built with FastAPI.

## Architecture

The project follows **Separation of Concerns** with three layers:

- **Controllers**: Handle HTTP requests/responses
- **Services**: Contain business logic
- **Repositories**: Manage database operations

## Tech Stack

- FastAPI - Web framework
- SQLAlchemy - ORM
- PostgreSQL - Database
- JWT - Authentication
- Pydantic - Data validation

## Setup Instructions

### Prerequisites

- Python 3.9+
- PostgreSQL

### Installation

1. Clone repository

```bash
git clone <your-repo-url>
cd ai-vacation-planner
```
